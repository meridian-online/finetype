### ac-03 Detail

The spec requires "4 regression pairs + 8 confusion pairs inspected with sample data and overlap analysis." The dedicated ac-03 section covers only the 4 regressions. However, training data inspection for 12+ confusion pairs is documented inline within the per-item audits (items 1, 2, 3, 4, 6, 7, 9, 10, 11, 13, 16, 19). The information is present but not consolidated into the ac-03 section. This is a structural shortfall, not a content gap. Not blocking.

### ac-05 Detail

Zero GT corrections is credible. The prior audit (v2, 2026-04-12) corrected 6 GT labels and expanded interchangeability rules. The 23 remaining misclassifications are all analysed with sample values showing clear model error or training data issues (e.g., user agents classified as JWT, SHA-256 hashes classified as ethereum addresses). None are ambiguous enough to question GT.

## Issues

### Minor

1. **ac-03 structure:** The 8 confusion pairs required by the spec are documented inline in per-item audits, not consolidated in the ac-03 section. The section title says "Regression Pairs" and only covers 4. Suggest renaming the section or adding a "Key Confusion Pairs" subsection that cross-references the relevant items.

2. **Unrelated .claude/settings.json change:** The permissions block was removed. This should be excluded from the commit or committed separately.

3. **CLAUDE.md stale:** The project CLAUDE.md still references v11 as the default model with 201/227. Should be updated to reflect v12 at 204/227 if this work is being shipped, but that's outside the scope of this spec.

### Observations (non-blocking)

- The confidence analysis is high quality. The finding that the validation branch provides correct signal in 4/6 cases but is overridden by char/embed branches is well-evidenced and directly actionable.
- The retrain brief is well-structured with clear priority tiers and expected impact. P1 (distilled data decontamination) is low-effort, high-confidence.
- The bug fix (vb.pp prefix mismatch) explains the initially puzzling "v12 matches v11 exactly" result — the validation branch was silently disabled.
