# Allowlist for scripts/check-public-hygiene.sh.
#
# Format, one entry per line, THREE pipe-separated fields:
#
#     <tracked file path or glob> | <exact matched text> | why this one is legitimate
#
# `|` is the separator because no rule pattern can ever match a `|`, so the
# matched text can never collide with it. All three fields are required; an entry
# that does not parse, or whose explanation is empty, fails the check with exit 2,
# so nothing is waved through silently.
#
# Line numbers are not part of an entry — they drift. Instead, every entry must
# match something: an entry that suppresses nothing is exit 2 too, so a stale
# allowlist cannot rot into fake coverage.
#
# ═══════════════════════════════════════════════════════════════════════════════
# THE TEST FOR ADDING A LINE HERE
# ═══════════════════════════════════════════════════════════════════════════════
#
# A hygiene sweep may rewrite text that DESCRIBES the work. It may never rewrite
# text that IS the data.
#
# Everything below is on the second side of that line: a value some other
# artefact joins on, a path a program opens, or a recorded provenance that stops
# being true the moment it is edited. Nothing below is prose. If what you are
# looking at is a sentence, fix the sentence instead — the gate's failure message
# shows the rewrite it wants.
#
# ═══════════════════════════════════════════════════════════════════════════════
